# AI Gear Hub — Affiliate Website Starter

This is a free static affiliate-marketing website starter.

## What is included
- Responsive homepage
- AI tools category filters
- Search
- AI accessories / gear section
- Comparison cards
- Editorial guide area
- Affiliate disclosure
- Newsletter placeholder
- Mobile navigation

## Before publishing
1. Open `index.html`.
2. Search for `YOUR-AFFILIATE-LINK` and replace every placeholder with your real approved affiliate URLs.
3. Replace the sample product names and descriptions with products you genuinely review/recommend.
4. Create real Privacy, Terms and Contact pages before collecting personal data.
5. Connect the newsletter form to an email provider if you want to collect emails.
6. Add your own logo/site name if you don't want to use "AI Gear Hub".
7. Check each affiliate program's rules for disclosures, trademarks, pricing claims and paid search.

## Publish for free with GitHub Pages
- Create a free GitHub account.
- Create a new public repository.
- Upload `index.html`, `styles.css`, and `script.js`.
- In repository Settings → Pages, enable publishing from the main branch.
- GitHub will provide a free `github.io` address.

You can later buy a custom domain and point it to the site.

## Important
This starter does not contain real affiliate relationships. You must apply to affiliate programs yourself and use only approved links.

The product names in this starter are generic placeholders, deliberately avoiding false claims about specific brands.
